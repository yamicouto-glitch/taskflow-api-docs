## Base URL

```
https://test-writechoice.onrender.com/
```

## Authentication

Every request requires a Bearer token in the `Authorization` header:

```
Authorization: Bearer tf-live-4a8f2c1e9b3d7e6a
```

Requests without a valid key return `401 Unauthorized`. There's no separate login or token-refresh step — the key itself is the credential.

## Endpoints

| Method | Path | Description |
|---|---|---|
| `POST` | `/projects` | Create a project |
| `POST` | `/tasks` | Create a task in a project |
| `GET` | `/projects/{project_id}/tasks` | List all tasks in a project |
| `PATCH` | `/tasks/{task_id}` | Update a task's title, description, or status |
| `DELETE` | `/tasks/{task_id}` | Permanently delete a task |

<Note>
  Not sure what order to call these in? Start with [Core Workflow](/guides/core-workflow) — projects and tasks depend on each other, and calling them out of order is the most common source of errors.
</Note>

## Response format

Successful responses return the resource (or list of resources) as JSON, matching the shapes below.

  </Accordion>
  <Accordion title="Task object">
